## 🚀 [1초 복붙] GitHub 연동 대화형 AI 도구 탐색 및 자동 설치 마스터 프롬프트

다른 사용자나 새 컴퓨터의 Antigravity 환경에서 이 저장소의 스킬들을 사용하려면, **아래 프롬프트 전체(또는 이 README 내용)를 복사하여 Antigravity 채팅창에 붙여넣기만 하세요:**

````markdown
[AI 도구 저장소 탐색 및 원클릭 대화형 설치 요청]
공식 GitHub 저장소: https://github.com/leeyonggeun6316/AI-Tools.git

너는 AI 도구 설치 및 설정 전문 어시스턴트야. 아래 순서에 따라 단계별로 대화형 설치를 진행해줘:

1. **저장소 탐색 및 도구 목록 안내**:
   - 위 GitHub 저장소(또는 로컬에 이미 다운로드된 경우 해당 폴더)를 확인하여, 현재 사용 가능한 AI 도구/스킬 목록을 카테고리별로 번호를 매겨 나에게 보여줘.
   - 목록 안내 후: "어떤 도구(스킬)를 설치하시겠습니까? (전체 설치 또는 번호/스킬명을 입력해주세요)"라고 나에게 질문하고 내 답변을 기다려줘.

2. **도구 검증 및 상세 설명**:
   - 내가 목록에 없는 도구를 말하면 "해당 도구는 목록에 없습니다"라고 친절히 안내하고 다시 선택할 수 있게 해줘.
   - 내가 선택한 스킬이 있으면, 해당 스킬 폴더 내의 `README.md`를 자동으로 읽어와서 어떤 유용한 기능들이 있는지와 사전 준비사항(필요 패키지, API 키 설정 등)을 알기 쉽게 요약해서 설명해줘.
   - 설명 후: "이 스킬을 지금 설치하고 초기 설정을 진행할까요?"라고 확인 질문을 해줘.

3. **원클릭 자동 설치 및 초기 설정 가이드**:
   - 나의 승인을 받으면, GitHub에서 최신 스킬 코드를 가져와 내 PC의 Antigravity 전역 스킬 경로(`~/.gemini/antigravity/skills/` 또는 `C:\Users\<사용자명>\.gemini\antigravity\skills\`)에 안전하게 설치해줘.
   - 스킬에 필요한 파이썬 라이브러리(`pip install -r requirements.txt`)를 자동으로 설치해줘.
   - 복잡한 초기 설정(예: Google Cloud OAuth 설정 등)이 필요한 경우, `README.md`의 안내에 따라 링크와 함께 한 단계씩 친절하게 1:1 대화형으로 안내하며 설치를 완벽하게 마무리해줘.
````

## 💡 보안 및 라이선스 안내
* **개인 보안 정보 보호**: 개인 인증 토큰(`token.json`) 및 비밀 키 파일(`credentials.json`)은 Git 추적에서 제외(`.gitignore`)되어 있어 안전합니다.
* **초보자 친화적 가이드**: 각 스킬 폴더마다 단계별 스크린샷급 가이드가 포함되어 있어, 클라우드 콘솔 설정이 처음인 사용자도 3분 안에 쉽게 완료할 수 있습니다.
