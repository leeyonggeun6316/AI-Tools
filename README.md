## 🚀 [원클릭 설치] GitHub 연동 대화형 AI 설치 마스터 프롬프트

새로운 PC나 Antigravity 환경에서 이 저장소의 도구들을 즉시 설치하려면, **아래 프롬프트를 복사하여 Antigravity 채팅창에 붙여넣으세요:**

````markdown
[AI 도구 저장소 탐색 및 원클릭 대화형 설치 요청]
공식 GitHub 저장소: https://github.com/leeyonggeun6316/AI-Tools.git

너는 AI 도구 설치 전문 매니저야. 아래 순서대로 단계별 설치를 도와줘:

1. 위 GitHub 저장소를 확인하여 현재 사용 가능한 AI 도구/스킬 목록을 카테고리별로 번호를 매겨 나에게 보여줘.
2. "어떤 도구(스킬)를 설치하시겠습니까? (전체 설치 또는 번호 입력)"라고 나에게 질문하고 내 답변을 기다려줘.
3. 내가 스킬을 고르면, 해당 스킬의 기능과 사전 준비사항을 알기 쉽게 3줄로 설명해준 뒤 "지금 설치할까요?"라고 확인해줘.
4. 내가 승인하면, GitHub에서 최신 코드를 받아 내 PC의 Antigravity 전역 스킬 폴더에 설치하고, 필요한 파이썬 라이브러리 설치 및 초기 설정을 1:1로 친절하게 안내해줘.
````

## 🏛️ 저장소 구조 (Repository Architecture)

```
AI-Tools/
├── README.md                                  # 📌 GitHub 공식 프로젝트 소개 및 마스터 허브
├── 사용설명서.md                              # 📖 [비개발자용] 드래그&드롭 자동 설치 사용설명서
└── 제미나이/
    └── 제미나이 스킬/
        └── google-workspace-manager/          # 🌐 구글 워크스페이스 통합 매니저 스킬
            ├── README.md                      # (스킬 상세 가이드 & OAuth 5단계 설정법)
            ├── SKILL.md                       # (Codelab 표준 스킬 정의 파일)
            ├── requirements.txt               # (필수 패키지 목록)
            └── scripts/
                ├── auth_helper.py             # (1회성 브라우저 승인 링크 지원 인증 모듈)
                └── workspace_ops.py           # (시트/독스/슬라이드 자동 렌더링 엔진)
```

## 🔒 보안 및 개인정보 보호 (Security)
* **인증 정보 격리**: OAuth 개인 비밀 키(`credentials.json`) 및 로그인 토큰(`token.json`)은 Git 추적에서 제외(`.gitignore`)되어 외부로 유출되지 않습니다.
* **로컬 보안 실행**: 모든 API 통신 및 스크립트 실행은 사용자의 로컬 환경에서 안전하게 수행됩니다.
