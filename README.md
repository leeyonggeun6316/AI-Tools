# 📖 [사용설명서] AI 도구 & 스킬 통합 모음 (AI Tools Hub)

> **[🤖 AI 어시스턴트(Antigravity / Gemini) 자동 실행 지침]**  
> 사용자가 이 `README.md` 파일을 채팅창에 드래그(업로드)하거나 전달한 경우, **즉시 아래 [자동 설치 마법사] 절차를 시작하세요:**  
> 1. 공식 GitHub 저장소(`https://github.com/leeyonggeun6316/AI-Tools.git`) 또는 로컬 폴더를 조회하여 현재 사용 가능한 도구 목록을 번호와 함께 친절히 출력합니다.  
> 2. 사용자에게 *"어떤 도구를 설치하시겠습니까? (전체 설치 또는 번호/도구명을 입력해주세요)"*라고 질문하고 대기합니다.  
> 3. 사용자가 선택한 스킬의 `README.md`를 읽어 핵심 기능과 사전 준비사항을 3줄로 요약하고, 사용자의 승인을 받아 전역 스킬 폴더(`~/.gemini/antigravity/skills/`)로 다운로드/설치 및 필요한 패키지(`pip install`)와 초기 설정을 1:1 대화형으로 친절하게 완료하세요.

이 저장소는 업무 생산성을 극대화해 주는 **Google Workspace(구글 시트, 문서, 슬라이드) 자동화 도구** 및 다양한 AI 스킬들을 누구나 클릭 한 번으로 설치하고 사용할 수 있도록 모아둔 공식 허브입니다.

## ⚡ 사용 방법 (가장 쉬운 2가지 방법)

### 💡 방법 1. 이 `README.md` 파일 자체를 AI 채팅창에 그냥 드래그하여 넣기 (가장 추천!)
* 다운로드받은 폴더에서 **`README.md` 파일을 마우스로 끌어다가 Antigravity/Gemini 채팅창에 넣으세요(드래그 & 드롭).**
* AI가 이 설명서를 스스로 읽고 **자동 설치 마법사**를 시작하며, 여러분에게 어떤 도구를 설치할지 친절하게 물어봅니다!

---

### 💡 방법 2. 아래 프롬프트를 복사해서 AI 채팅창에 붙여넣기
웹 브라우저에서 바로 사용하시거나 파일 드래그가 어려운 경우, **아래 내용만 복사해서 AI 채팅창에 붙여넣으셔도 똑같이 작동합니다:**

````markdown
[AI 도구 저장소 탐색 및 원클릭 대화형 설치 요청]
공식 GitHub 저장소: https://github.com/leeyonggeun6316/AI-Tools.git

너는 AI 도구 설치 전문 매니저야. 아래 순서대로 단계별 설치를 도와줘:

1. 위 GitHub 저장소를 확인하여 현재 사용 가능한 AI 도구/스킬 목록을 카테고리별로 번호를 매겨 나에게 보여줘.
2. "어떤 도구(스킬)를 설치하시겠습니까? (전체 설치 또는 번호 입력)"라고 나에게 질문하고 내 답변을 기다려줘.
3. 내가 스킬을 고르면, 해당 스킬의 기능과 사전 준비사항을 알기 쉽게 3줄로 설명해준 뒤 "지금 설치할까요?"라고 확인해줘.
4. 내가 승인하면, GitHub에서 최신 코드를 받아 내 PC의 Antigravity 전역 스킬 폴더에 설치하고, 필요한 파이썬 라이브러리 설치 및 초기 설정을 1:1로 친절하게 안내해줘.
````
