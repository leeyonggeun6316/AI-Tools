## 🚀 [1초 복붙] 대화형 AI 도구 탐색 및 자동 설치 마스터 프롬프트

새 컴퓨터나 다른 사람의 Antigravity 환경에서 이 저장소의 도구들을 쉽게 탐색하고 설치하려면, **아래 프롬프트를 복사하여 Antigravity 채팅창에 붙여넣으세요:**

````markdown
[AI 도구 탐색 및 자동 설치 요청]
저장소 경로: C:\Users\<본인사용자명>\Desktop\AI 툴 (또는 현재 워크스페이스)

1. 먼저 위 저장소의 폴더와 README.md를 분석하여, 현재 사용 가능한 AI 도구/스킬 목록을 카테고리별로 알기 쉽게 번호를 매겨 나에게 보여줘.
2. 목록을 보여준 뒤, "어떤 도구(스킬)를 설치하시겠습니까? (전체 설치 또는 번호/스킬명을 입력해주세요)"라고 나에게 질문해줘.
3. 내가 원하는 스킬을 선택하면:
   - 만약 목록에 없는 것을 입력하면 "해당 도구는 목록에 없습니다"라고 안내하고 다시 선택할 수 있게 해줘.
   - 목록에 있는 스킬을 선택하면 해당 스킬 폴더 내의 `README.md` 파일을 자동으로 읽어와서 기능 요약과 필요한 초기 설정(API 키, 의존성 패키지 등)을 나에게 설명해줘.
   - 나의 확인을 받은 후, 전역 스킬 경로(`C:\Users\<본인사용자명>\.gemini\antigravity\skills\`)로 필요한 파일들을 안전하게 복사하고 패키지 설치(`pip install -r requirements.txt`) 및 1회성 초기 세팅을 단계별로 대화형으로 안내하여 설치를 완료해줘.
````

## 💡 초기 세팅 및 보안 안내
* **API 인증 정보 보안**: Google Cloud OAuth 키(`credentials.json`) 및 인증 토큰(`token.json`)은 개인 고유 정보이므로 Git에 절대 커밋되지 않도록 `.gitignore`에 등록되어 있습니다.
* **초기 설정 지원**: 개별 스킬 폴더마다 상세한 `README.md`가 포함되어 있어, 복잡한 클라우드 콘솔 설정도 단계별로 따라하기만 하면 손쉽게 완료할 수 있습니다.
